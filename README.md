# 模拟电路 Multisim 仿真实例

整理的一组 Multisim 模拟电路仿真实例，涵盖运放运算电路、滤波器与功率放大电路等基础内容。

## 环境

- NI Multisim 14.0 或更高版本
- 工程文件为 `.ms14` 格式，需要用 Multisim 打开

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `circuits/01-低通滤波.ms14` | 低通滤波器，观察幅频特性与截止频率 |
| `circuits/02-加法器.ms14` | 运放加法运算电路 |
| `circuits/03-交越失真.ms14` | 互补推挽输出级的交越失真现象 |
| `circuits/04-设计1.ms14` | 综合设计练习 |
| `circuits/05-最新.ms14` | 综合设计练习 |
| `circuits/06-123321.ms14` | 练习 |
| `circuits/07-311.ms14` | 练习 |
| `circuits/08-aoye.ms14` | 练习 |

后几个文件的命名沿用当时的工程名，具体的电路结构和参数见文件内的原理图。

## 使用

用 Multisim 打开对应文件后可直接运行交互式仿真，配合示波器、波特图仪等虚拟仪器观察结果。
